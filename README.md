# WORLD END

> 世界で最初に100面のボスを倒した1人が、全プレイヤーのゲームを終わらせる。

スマートフォン（横向き・両手の親指操作）優先の高難度2D横スクロールアクション。
1〜79面はオートセーブ、**80〜100面はノーセーブ**の連続チャレンジ。
最後のボスを倒し、サーバーがクリアを承認した最初の1人で世界が終わります。

- ゲーム本体：TypeScript + Vite（Canvas 描画）→ GitHub Pages
- 状態API：Cloudflare Workers + D1（無料枠内）
- 画像・音：すべてコードで生成（外部素材なし）

## 遊ぶ・動かす

```bash
npm install
npm run dev        # http://localhost:5173 （スマホ実機は同じWi-Fiから http://<PCのIP>:5173）
```

サーバー未接続のときは「オフラインモード」で動きます（世界の終了判定なし）。
サーバーとつなぐ方法は **[docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)** を見てください。

### 操作

| | 移動 | ジャンプ | その他 |
| --- | --- | --- | --- |
| スマホ | 左下の ◀ ▶ | 右下の JUMP | 右上 II で一時停止 |
| PC | ← → / A D | Space / Z / ↑ | R：やり直し、Esc / P：一時停止 |

ゲームパッドにも対応しています。ボタンの大きさ・濃さ・位置はタイトルの「設定」で調整できます。

### テストプレイ用機能

URL の末尾に `?debug=1` を付けると、タイトル画面に **面選択・無敵** が出ます（一時停止メニューに「この面をスキップ」も出ます）。

- 例：`http://localhost:5173/?debug=1`
- 無敵・スキップを使ったチャレンジはサーバーに公式記録として送られません
- 本番公開時は GitHub の Actions 変数 `ALLOW_DEBUG` を `false` にすると完全に無効化されます

## ルール（企画書 Ver.2.0 準拠）

| 状況 | 復帰位置 |
| --- | --- |
| 1〜79面で死亡 | その面の最初 |
| 1〜79面をクリア | 次の面を自動保存 |
| 80面に到達 | 80面開始地点を最後のセーブとして記録 |
| 80〜100面で死亡・やり直し | 80面の最初へ |
| 80〜100面の途中で中断・再読込 | 80面の最初から |
| 100面ボス撃破 | サーバーへ申請。承認された最初の1名が勝者 |

## 構成

```
src/shared/     ブラウザとサーバーで共通のコード
  sim.ts        決定論的ゲームシミュレーション（整数演算のみ・60fps固定）
  stages.ts     100面のステージ生成（面番号から常に同じステージを生成）
  replay.ts     入力ログの圧縮と検証用の再生
  name.ts       プレイヤー名の検証
src/client/     ブラウザ側（描画・入力・音・UI・セーブ）
worker/         Cloudflare Workers の状態API と D1 のスキーマ
tools/          開発ツール（自動攻略ボット、ステージ表示、結合テスト）
docs/           Cloudflare の手順書
```

### 不正対策のしくみ

ゲームの物理計算は整数だけで行う「決定論的シミュレーション」になっていて、同じ面・同じ入力なら
ブラウザでもサーバーでも必ず同じ結果になります。80〜100面では1面クリアするごとに
**入力ログ（数十〜数百バイト）** をサーバーに送り、サーバーが同じシミュレーションで再生して
本当にクリアしているかを確認します。

- 面の順番飛ばし・偽のログ・死亡を含むログ → 拒否
- 実時間と合わない記録（極端に早い／一時停止しすぎ）→ 拒否
- 世界の終了は `UPDATE ... WHERE ended = 0` の条件付き更新 → 同時申請でも勝者は必ず1人

ただし企画書のとおり、ブラウザに配るプログラムである以上、完全なチート防止（自動操作ツール等）は保証できません。

## 開発ツール

```bash
npm run verify-stages          # 自動攻略ボットで全100面がクリア可能か検証（数分）
npm run solve -- 37            # 37面だけ検証
npm run preview-stage -- 37    # 37面の地形をテキストで表示
npm run e2e                    # ローカルサーバーとの結合テスト（docs参照）
```

## 本番公開の仕上げ（テストプレイ後に行う）

テストプレイ中はサーバーが **テストモード**（`MODE = "test"`）で動いており、100面をクリアしても
「検証成功」の記録が残るだけで世界は終わりません。テストが終わったら：

1. 難易度の調整を反映して push
2. `worker/wrangler.toml` の `MODE` を `"live"` に変更して `npm run deploy`（worker ディレクトリで）
3. 世界をリセット（テスト中のセッションを消す）：`/api/admin/reset`
4. GitHub の Actions 変数 `ALLOW_DEBUG` を `false` にして Pages を再デプロイ
5. 実機（iOS Safari / Android Chrome）で最終確認

この手順は確認しながら一緒に進められます。
