選択中の配置物

「選択」ツールで敵や移動床をクリックすると、ここで設定を変えられます。

操作

  • 左クリック／ドラッグ：置く
  • 右クリック／ドラッグ：消す
  • 数字キー 1〜9・0：ツール切替
  • P：テストプレイ（Esc で戻る、R でやり直し）
  • Ctrl+Z / Ctrl+Y：戻す／やり直す
  • 編集内容はこのブラウザに自動保存（下書き）されます。ゲームに反映するには「書き出し」

書き出し

下の内容が src/shared/stage-data.json の新しい中身です（下書きのある面＋すでに反映済みの手作り面）。

  1. 「ダウンロード」または「コピー」
  2. GitHub のリポジトリで src/shared/stage-data.json を開き、鉛筆アイコン（Edit）→ 全部置き換えて貼り付け → 「Commit changes」
  3. 数分で GitHub Pages のゲームに反映されます。サーバー（Cloudflare）を使っている場合は worker で npm run deploy も必要です

Claude に「このファイルを反映して」と渡してもらっても大丈夫です。
